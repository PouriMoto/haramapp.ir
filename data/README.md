# راهنمای وارد کردن اطلاعات

**همهٔ چیزهایی که خودتان تغییر می‌دهید فقط در همین پوشه است.** بقیهٔ پروژه (پوشهٔ `src` و ...) را لازم نیست لمس کنید.

| فایل | چه چیزی را کنترل می‌کند |
|---|---|
| `site.json` | آدرس Apps Script، دامنه، تعداد موارد صفحهٔ اصلی |
| `content.json` | دعاها، نواها، ویدیوها، بنرها (لینک‌ها و عنوان‌ها) |
| `prayers/<id>.md` | متن هر دعا (اختیاری) |
| `causes.json` | کارت‌های همیاری: نام، شماره کارت، شبا |
| `banners/` | تصویر بنرها (اختیاری؛ یا از لینک https استفاده کنید) |

بعد از هر تغییر، `npm run dev` را بزنید و در مرورگر ببینید. اگر چیزی اشتباه باشد، همان‌جا **به فارسی** می‌گوید کجا و چرا.

---

## ۱) `site.json`
```json
{
  "appsScriptUrl": "https://script.google.com/macros/s/XXXX/exec",
  "domain": "",
  "homeLimit": 3
}
```
- `appsScriptUrl`: آدرس Web App که از Apps Script گرفتید (باید به `/exec` ختم شود). **خالی = داده نمایشی** (برای دیدن ظاهر).
- `domain`: **فقط وقتی** DNS دامنه را تنظیم کرده‌اید، مثلاً `"haramapp.ir"`. تا آن موقع خالی بگذارید (سایت روی `github.io/نام-ریپو` بالا می‌آید).
- `homeLimit`: چند دعا/نوا/ویدیو در صفحهٔ اصلی.

## ۲) `content.json`

### دعا
```json
{ "id": "tavassol", "title": "دعای توسل", "audio": "https://file.erfan.ir/…/tavassol.mp3", "categories": ["other"] }
```
- `id`: انگلیسی کوچک، بدون فاصله (یک بار انتخاب کنید و عوض نکنید).
- `audio`: لینک **مستقیم فایل mp3** (نه صفحهٔ پلیر). اختیاری.
- `categories`: یکی از `fatemiyeh`، `muharram`، `ramadan`، `qadr`، `other`.
- متن دعا: فایل `prayers/tavassol.md` (با همان `id`). اگر نباشد فقط صوت نمایش داده می‌شود.

### نوای معنوی
```json
{ "title": "ای صفای قلب زارم", "artist": "نام هنرمند", "src": "https://…/file.mp3", "categories": ["other"] }
```

### ویدیو (آپارات)
```json
{ "title": "صلوات خاصه امام رضا (ع)", "aparat": "ckn3o4e", "featured": true }
```
- `aparat`: شناسهٔ کوتاه ویدیو. در کد embed آپارات، بخش بعد از `videohash/` است. (در `…/videohash/ckn3o4e/vt/frame` همان `ckn3o4e`).
- `featured: true`: ویدیوی معرفی که **بالای صفحهٔ اصلی** می‌آید (فقط یکی).

### بنر
```json
{ "id": "ramadan-1405", "kind": "campaign", "title": "ماه رمضان", "href": "/prayers?cat=ramadan", "endsAt": "2027-03-20" }
```
- `kind`: `campaign` (مراسم/کمپین) یا `ad` (تبلیغ؛ با `sponsor` نام حامی).
- `image`: لینک https تصویر، یا نام فایلی که در `banners/` گذاشته‌اید (نسبت ۳ به ۱، مثل ۱۲۰۰×۴۰۰).
- `href`: لینک https یا مسیر داخلی مثل `/help`. `startsAt` / `endsAt` اختیاری.

### ترتیب
**ترتیب نمایش همان ترتیب فهرست است** (بالاترین = اول). `"pinned": true` یک مورد را همیشه اول می‌آورد.

### سایت جدید برای لینک صوت
فقط سایت‌های داخل `allowedHosts` (بالای `content.json`) پذیرفته می‌شود. اگر از سایت دیگری لینک می‌گیرید، دامنه‌اش را همان‌جا اضافه کنید.

## ۳) `causes.json` (همیاری)
هر کارت یک بلوک است. فقط `""`ها را پر کنید:
```json
"bank": { "bankName": "ملی", "ownerName": "نام صاحب حساب", "cardNumber": "6037…", "iban": "IR…" }
```
- شماره کارت ۱۶ رقم، شبا با `IR` (هنگام کپی، `IR` حذف می‌شود).
- کارت چندحسابه (مثل امامزاده): هر حساب در `accounts` بانک خودش را دارد.
- کارت جدید = یک بلوک تازه با `id` یکتا. خودکار قابل جستجو می‌شود.
- `online` را فعلاً `false` نگه دارید (پرداخت آنلاین بعداً).

## ۴) انتشار
```
git add .
git commit -m "محتوای جدید"
git push
```
حدود ۲ دقیقه بعد سایت به‌روز است. نیازی به هیچ کار دیگری نیست.

## خطاهای رایج
| پیام | معنی |
|---|---|
| `JSON نامعتبر` | کاما یا گیومه یا آکولاد جاافتاده/اضافه؛ آخرین مورد هر فهرست کاما ندارد |
| `«id» لازم است` | برای هر دعا یک `id` انگلیسی بنویسید |
| `باید لینک https … باشد` | لینک با `https://` شروع نمی‌شود یا سایتش در `allowedHosts` نیست |
| `دستهٔ ناشناخته` | نام دسته غلط است؛ فهرست مجاز در پیام آمده |
